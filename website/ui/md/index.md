# AI.OpenSubtitles.com

> AI subtitle transcription and translation from the team behind opensubtitles.com. Transcribe media to subtitles, translate subtitle files into dozens of languages, and search the opensubtitles.com subtitle catalog. The website is a live demo of the AI API plus the app versions.

## What it does

- **Transcription**: turn any video or audio file into accurate subtitles automatically.
- **Translation**: translate SRT and VTT files into dozens of languages.
- **Search**: find and download subtitles from the opensubtitles.com catalog — free, see [Search & download subtitles](https://ai.opensubtitles.com/search.md).

## How it works

1. Drop in a media or subtitle file.
2. AI transcribes or translates it.
3. Download your subtitles (SRT or VTT).

Media files are converted locally in your browser to a mono MP3 — only the audio track is uploaded for transcription. Subtitle files are uploaded as-is.

## Accounts & credits

- You use your existing opensubtitles.com account. Credits are shared across the website and the apps.
- Credits are the pay-as-you-go currency for AI transcription and translation: see [pricing](https://ai.opensubtitles.com/pricing.md).
- Failed jobs are never charged.

## Apps

The web app is a light version of the desktop app: fewer features, but it handles most jobs smoothly right in the browser. The desktop app isn't bound by browser limits and handles larger files.

- Desktop app releases: https://github.com/iceman1010/ai-opensubtitles-desktop-client/releases/latest
- Web app: https://ai.opensubtitles.com/ai-web

## File types

Media files are transcribed; subtitle files like SRT and VTT are translated. Everything else is handled for you automatically.
