หากคุณดำเนินการเรียกดูและใช้งานเว็บไซต์นี้ต่อไป แสดงว่าคุณยอมรับที่จะปฏิบัติตามและผูกพันตามข้อกำหนดและเงื่อนไขการใช้งานดังต่อไปนี้ ซึ่งร่วมกับนโยบายความเป็นส่วนตัวของเรากำกับความสัมพันธ์ระหว่าง AI.OpenSubtitles.com กับคุณเกี่ยวกับเว็บไซต์นี้

คำว่า 'AI.OpenSubtitles.com' หรือ 'เรา' หมายถึงเจ้าของเว็บไซต์ คำว่า 'คุณ' หมายถึงผู้ใช้หรือผู้เข้าชมเว็บไซต์นี้

การใช้งานเว็บไซต์นี้อยู่ภายใต้ข้อกำหนดการใช้งานดังต่อไปนี้:

  • เนื้อหาของหน้าเว็บไซต์นี้มีไว้สำหรับข้อมูลทั่วไปและการใช้งานของคุณเท่านั้น และอาจเปลี่ยนแปลงได้โดยไม่ต้องแจ้งให้ทราบล่วงหน้า
  • เว็บไซต์นี้ใช้คุกกี้เพื่อติดตามความชอบในการเรียกดู
  • ทั้งเราและบุคคลที่สามไม่ให้การรับประกันใด ๆ เกี่ยวกับความถูกต้อง ความทันสมัย ประสิทธิภาพ ความสมบูรณ์ หรือความเหมาะสมของข้อมูลและเอกสารที่พบหรือนำเสนอบนเว็บไซต์นี้สำหรับวัตถุประสงค์ใด ๆ โดยเฉพาะ คุณยอมรับว่าข้อมูลและเอกสารดังกล่าวอาจมีความไม่ถูกต้องหรือข้อผิดพลาด และเราขอปฏิเสธความรับผิดชอบต่อความไม่ถูกต้องหรือข้อผิดพลาดดังกล่าวอย่างชัดแจ้งในขอบเขตสูงสุดที่กฎหมายอนุญาต
  • การใช้ข้อมูลหรือเอกสารใด ๆ บนเว็บไซต์นี้เป็นไปตามความเสี่ยงของคุณเองทั้งหมด ซึ่งเราจะไม่รับผิดชอบ เป็นความรับผิดชอบของคุณเองที่จะต้องตรวจสอบให้แน่ใจว่าผลิตภัณฑ์ บริการ หรือข้อมูลที่มีให้ผ่านเว็บไซต์นี้ตรงตามความต้องการเฉพาะของคุณ
  • เว็บไซต์นี้มีเอกสารที่เป็นของเราหรือได้รับอนุญาตให้ใช้ เอกสารเหล่านี้ประกอบด้วยแต่ไม่จำกัดเพียงการออกแบบ เลย์เอาต์ ลักษณะที่ปรากฏ และกราฟิก การทำซ้ำเป็นสิ่งต้องห้าม นอกจากจะเป็นไปตามประกาศเรื่องลิขสิทธิ์ ซึ่งเป็นส่วนหนึ่งของข้อกำหนดและเงื่อนไขเหล่านี้
  • เครื่องหมายการค้าทั้งหมดที่ปรากฏบนเว็บไซต์นี้ซึ่งไม่ใช่ทรัพย์สินของผู้ดำเนินการหรือไม่ได้รับอนุญาตให้ผู้ดำเนินการใช้ จะได้รับการรับรองบนเว็บไซต์
  • การใช้งานเว็บไซต์นี้โดยไม่ได้รับอนุญาตอาจก่อให้เกิดคำเรียกร้องชดใช้ค่าเสียหาย และ/หรือถือเป็นความผิดทางอาญา
  • เป็นครั้งคราว เว็บไซต์นี้อาจมีลิงก์ไปยังเว็บไซต์อื่น ๆ ลิงก์เหล่านี้จัดทำขึ้นเพื่อความสะดวกของคุณในการให้ข้อมูลเพิ่มเติม ลิงก์เหล่านี้ไม่ได้หมายความว่าเรารับรองเว็บไซต์ดังกล่าว เราไม่มีความรับผิดชอบต่อเนื้อหาของเว็บไซต์ที่เชื่อมโยง
  • ระบบเครดิตบนเว็บไซต์นี้ใช้เพื่อให้ผู้ใช้เข้าถึง API ของบุคคลที่สามหลายตัวที่ใช้ในการให้บริการ เช่น การถอดเสียงภาพยนตร์/เสียงเป็นคำบรรยายใต้ภาพ การแปลคำบรรยายใต้ภาพ และการสร้างเสียงบรรยายจากคำบรรยายใต้ภาพ/คำบรรยายใต้ภาพที่แปลแล้ว ผู้ใช้สามารถซื้อเครดิตบนเว็บไซต์นี้และใช้เพื่อเข้าถึงบริการเหล่านี้ จำนวนเครดิตที่ต้องใช้สำหรับแต่ละบริการอาจแตกต่างกันและกำหนดโดยผู้ให้บริการ API ของบุคคลที่สาม
