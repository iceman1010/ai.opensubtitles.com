Cari subtitle

Cari subtitle film dan serial dalam puluhan bahasa. Untuk mengunduh subtitle yang sudah ada, Anda perlu masuk. Jika subtitle dalam bahasa yang diinginkan tidak tersedia, Anda bisa membuatnya dengan AI (terjemahan otomatis + pemeriksaan kualitas) sesuai permintaan. Kredit akan digunakan untuk mendapatkan file subtitle SRT lengkap.

Terjemahkan hasil tanpa mengunggah ulang

Setiap subtitle di hasil memiliki tombol Terjemahkan. Satu klik menyerahkan file tersebut langsung ke penerjemah AI — tanpa mengunduh, tanpa mengunggah terpisah. Di halaman pekerjaan Anda memilih bahasa target, dan file SRT atau VTT yang sudah jadi kembali kepada Anda. Terjemahan adalah layanan berbayar.
